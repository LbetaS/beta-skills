# 六种纯口播模式

## 1. 创业事故

发生事故 → 对方质疑 → 棘手之处 → 为什么继续 → 一个真实希望 → 下一步悬念。

适合：被拒、成本压力、项目危机、外界质疑。

## 2. 创业选择题

必须做选择 → A 的代价 → B 的代价 → 已知事实 → 主人公倾向 → 邀请判断。

适合：签对赌、涨价、贷款、免费策略、定制还是平台。

## 3. 行业观点

反常识结论 → 普遍做法 → 钱/资源/人的利益变化 → 案例或类比 → 对明确人群的结论。

适合：AI 转型、应用创业、Token 生意、职场变化。

## 4. 用户利益

点名人群 → 正在承担的成本 → 旧办法为何低效 → 新办法改变什么 → 具体收益 → 自然承接。

适合：老板降本、职场竞争力、管理流程、个人创业。

## 5. 用户反馈与小胜利

外界不看好 → 真实用户行为 → 小结果 → 它证明了什么 → 创始人情绪变化 → 新阶段。

适合：首笔付费、主动推荐、留存、用户带来客户或投资人。

## 6. 融资连续剧

当前地点/动作 → 要见谁 → 为什么可能有兴趣 → 本次结果意味着什么 → 留悬念。

适合：出发、见面前、谈完复盘、出现新机会。默认写短，不重讲完整产品背景。

## 选择规则

- 有两难决定：选“创业选择题”。
- 有明确截止日期、目标、差距、后果：用“创业事故”，以倒计时结构呈现。
- 有真实用户动作：优先“用户反馈与小胜利”。
- 只是在路上或准备见人：用“融资连续剧”。
- 核心是商业判断：用“行业观点”。
- 核心是用户能得到什么：用“用户利益”。

一条只能有一个主模式。产品介绍不是独立模式，只能承接主矛盾。
