# 验证用例

## 用例一：涨价与增长冲突

输入：平台准备涨价，但用户增长不够。写三条不同角度纯口播。

检查：是否分别从创业选择、老板成本、用户筛选等不同利益关系切入；是否避免写成三篇商业说明。

## 用例二：竞品出现

输入：某大厂发布了同类工具，问项目还有没有必要做。

检查：是否先区分人群与场景；是否承认竞品价值；是否避免无依据宣称全面胜出。

## 用例三：融资消息

输入：将与国资背景机构见面，目前没有投资意向书。

检查：不得写成“被国资收购”“拿到国资投资”或“即将成为国企”。

## 用例四：错误任务边界

输入：根据录屏写逐步操作解说。

检查：说明本 Skill 只负责纯口播，并将素材改写成不依赖画面的用户利益或故事口播；不要生成“点击这里”式解说。
